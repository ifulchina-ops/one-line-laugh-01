One funny sentence about the five alarms I set every night — and the
disappointed committee they have become by morning. `main.py` writes that
single sentence to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```
